## ✨ Website Features & Interactive Modules

1. **Direct 1-Click APK Download & Dynamic QR Code**:
   - Visitors can download the Android APK with a single click or scan the high-contrast camera QR code directly from their mobile screen.
2. **Interactive AI Disease Doctor Simulator**:
   - Live interactive plant pathology demo testing Tomato, Potato, Cotton, Rice, Sugarcane, and Chilli.
   - Simulates MobileNetV3 inference scanning, displaying confidence metrics (98.6%), CIBRC active chemical prescriptions, dilution, and low-cost bio-agent remedies.
3. **Soil Health NPK & 50kg Fertilizer Calculator**:
   - Interactive farm calculator taking crop type, acreage, soil test status, and pH.
   - Computes exact commercial 50kg bags of Urea (46% N), DAP (18-46-0), and MOP (60% K₂O), along with agricultural lime/gypsum soil amendments and 3-stage split application schedules.
4. **Live APMC Mandi Price Tracker**:
   - Searchable wholesale price monitor tracking Kolhapur, Pune, Nashik, Nagpur, and Mumbai mandis with MSP benchmark comparisons and 7-day trend indicators.
5. **Multilingual Voice Assistant Showcase**:
   - Interactive voice synthesizer supporting Marathi (मराठी), Hindi (हिंदी), and English with animated audio waves and localized voice responses.
6. **App Screenshots Gallery**:
   - High-resolution Material 3 Jetpack Compose application screen captures across Marathi localization, farm tools, voice AI, and community feed.

## 🚀 GitHub Pages (Hosting)

This website is hosted directly from the `main` branch:
1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
4. The site is live at: [https://sarveshjoshi242.github.io/krishi-aadhar-website/](https://sarveshjoshi242.github.io/krishi-aadhar-website/)
